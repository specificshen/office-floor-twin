# 12F · 办公层数字孪生

一层 CBD 办公楼的微俯视 3D 数字孪生演示：揭掉天花板看清会议室、工位、电梯厅和前台，用时间轴切换「现在 / 今天上午 / 典型周二」的占用状态。

## 本地打开

需要 Node.js 20 或 24（推荐 24 LTS），以及现代桌面浏览器。

```bash
npm install
npm run dev
```

然后在浏览器打开终端里提示的地址，一般是 [http://localhost:5173/](http://localhost:5173/)。请使用本地 http 服务打开，不要用 `file://` 直接打开源码。

已经构建过的 `dist/` 也可以这样预览：

```bash
npm run build
npm run preview
```

预览地址一般是 [http://localhost:4173/](http://localhost:4173/)。或者在项目根目录执行 `npx serve dist`。

## 交互说明

- **点房间**：镜头平滑飞入该房间，右侧切换为房间详情。建议先试中型会议室 M2、大会议室 L、前台、东侧工位区。
- **点楼板或走道空白处**：镜头回到整层总览，右侧回到整层摘要。
- **底部时间轴**：在「现在 14:20」「今天 10:00」「典型周二 14:20」之间切换，会议室亮起、工位点位和顶部五项状态会一起变化。
- **左下角楼栋剖面**（10F–15F，12F 高亮）：点击后提示「换层后续再做」，不会真正换层。
- 可轻微拖拽平移或滚轮缩放，主交互仍是点选飞入。
- 场景里的人是匿名低多边形模型，不显示姓名或可追踪 ID。

## 技术

Vite + React + TypeScript + Three.js（WebGLRenderer，经 @react-three/fiber）。资产已打包，运行时不依赖外部 CDN。第一批家具、人和电梯轿厢在 `public/models/`（16 个 `.glb`），约定见 `MODEL_BRIEF.md`。`screenshots/` 是当前场景截图。
